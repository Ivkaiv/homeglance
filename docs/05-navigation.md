# 05 · Страницы и навигация

## Концепция

Glance — это **дашборд из нескольких страниц**. Пользователь переключается между ними через нижний **dock-bar** в стиле macOS Sock.

Примеры структур:
- Простая: `Главная` (всё на одной странице)
- Средняя: `Дом · Кухня · Гостиная · Камеры`
- Сложная: `Дом · Климат · Свет · Безопасность · Медиа · Энергия`

## Страница

```ts
interface Page {
  id: string;             // 'home', 'kitchen', 'cameras' (auto-generated на основе title)
  title: string;          // 'Дом', 'Кухня', 'Камеры'
  icon: string;           // 'mdi:home' / 'mdi:silverware-fork' / эмодзи
  widgets: WidgetConfig[];
  /** Защита от изменения (например главная не удаляется) */
  protected?: boolean;
}
```

Каждая страница — независимая раскладка с собственным набором виджетов.

## Dock-bar

Расположение: внизу экрана, fixed, поверх контента. На широких экранах (desktop) — **посередине** с маленьким отступом.

### Внешний вид

- Закруглённые края (radius-full)
- Стеклянный фон (frosted glass)
- Лёгкая тень снизу
- Иконки страниц горизонтально
- Активная страница: чуть больше + glow + label

### Поведение

- **Тап** на иконку → переключение страницы (мгновенно или с slide-анимацией)
- **Долгий тап** → drag & drop порядка страниц
- **+** в правом конце dock'а (только в режиме edit) → создать новую страницу
- **Свайп влево/вправо** по основному экрану → следующая/предыдущая страница

```
            [iPhone screen]
   ┌─────────────────────────┐
   │                         │
   │     <widgets here>      │
   │                         │
   │                         │
   │                         │
   │                         │
   │  ┌────────────────────┐ │
   │  │ 🏠  💡  📷  📊  ⚙️ │ │  ← dock bar
   │  └────────────────────┘ │
   └─────────────────────────┘
```

## Создание / редактирование страниц

В режиме редактирования:

1. Жмёшь на dock-bar → ⋯ или жмёшь "+" → открывается **Page Manager** (sheet снизу)
2. Список текущих страниц с возможностью:
   - Изменить название и иконку
   - Удалить (если не protected)
   - Перетащить порядок
3. Кнопка **"+ Новая страница"** → форма:
   - Название (обязательно)
   - Иконка (выбор из MDI или эмодзи)
   - Шаблон (Пустая / Скопировать существующую)

## Навигация в коде

```ts
// stores/pages.ts
interface PagesState {
  pages: Page[];
  currentId: string;
}

// hooks
usePages() → pages array + actions (add/edit/delete/reorder)
useCurrentPage() → активная страница + её виджеты
```

URL-структура:
- `/` → главная страница
- `/p/kitchen` → страница "kitchen"
- `/p/{id}/edit` (опционально) → режим редактирования

## Заголовок страницы

Внутри каждой страницы — опциональный **header** сверху:

```
┌──────────────────────────┐
│ 🏠 Дом                   │  ← компактный header
│ 23 марта · вт            │
└──────────────────────────┘
```

Пользователь может в настройках страницы скрыть header или показать.

## Особые страницы

- **Глобальные настройки** — отдельная страница `/settings` (вне dock'а), доступ через шестерёнку в углу
- **Профиль** — `/profile` (для multi-user)
- **Каталог виджетов** — модальный, не страница

## Default-структура для нового пользователя

При первом запуске Glance создаёт:

```
Page "Дом"
  - Часы (top, full width)
  - Погода (left)
  - Температура улица (right)
  - Группа комнат (рядов с виджетами комнат)
```

Пользователь дальше сам перестраивает.

## Шаблоны страниц

В каталоге создания страницы — несколько готовых шаблонов:

- **Главная** — погода + комнаты
- **Безопасность** — камеры + сенсоры дверей/окон
- **Климат** — все термостаты + графики температур
- **Энергия** — счётчики + графики потребления
- **Медиа** — все плееры + быстрое управление
